# Welcome to Jouskaio.me Design System

This Storybook showcases the components used in the portfolio of **Jouskaio**.

## Project Overview

- **Framework:** Next.js
- **Styling:** SCSS (Atomic Design)
- **Data:** Apollo Client / GraphQL
- **Animations:** AOS (Animate On Scroll)
- **Code Highlighting:** highlight.js

## Installation

To install the library in your project, run:

```bash
yarn add @jouskaio/ui
# or
npm install @jouskaio/ui
```

### Usage

1. Import the **JouskaioProvider** in your application (e.g., in `_app.tsx` or `layout.tsx`). The provider automatically handles global styles and initializations like animations (AOS).

```tsx
import { JouskaioProvider } from '@jouskaio/ui';

function MyApp({ Component, pageProps }) {
  return (
    <JouskaioProvider>
      <Component {...pageProps} />
    </JouskaioProvider>
  );
}
```

2. Then you can use any component from the library:

```tsx
import { TextH1, CardStatus } from '@jouskaio/ui';

const MyPage = () => (
  <>
    <TextH1>Hello World</TextH1>
    <CardStatus title="Status" text="Everything is working fine!" />
  </>
);
```
