# Welcome to Jouskaio.me Design System

This Storybook showcases the components used in the portfolio of **Jouskaio**.

## Project Overview

- **Framework:** Next.js
- **Styling:** SCSS (Atomic Design)
- **Data:** Apollo Client / GraphQL
- **Animations:** AOS (Animate On Scroll)
- **Code Highlighting:** highlight.js

## Component Library

Browse the components in the sidebar to see their variations and test their behavior.
Every component marked with `ai-generated` has been set up with automated tests.

## Development

To start Storybook locally:

```bash
yarn storybook
```

To run tests:

```bash
yarn test-storybook
```
